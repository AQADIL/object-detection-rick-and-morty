# Object Detection — Rick and Morty

An interactive educational presentation about the R-CNN family, YOLO, SSD, intersection over union and non-maximum suppression.

**Team:** Akadil Alish, Erasyl Tortkara, Zhanibek Ibyrkhanov.

## Open the presentation

Open `index.html` in a browser or visit the GitHub Pages deployment. The presentation is self-contained and requires no installation, server, API keys or external requests.

Choose a portal or use the right arrow to begin. Left and right arrows move through the slides; the map icon, Home or Escape returns to the map. Press F for browser fullscreen. Swipe horizontally on touchscreens. Reduced-motion preferences are respected.

## Project

The page contains 17 slides, a layered 3D portal map, camera flights, pointer-responsive portals and an interactive answer reveal. Source code, styles and presentation assets are bundled in `index.html` so the same file also works offline.

Research and visual credits are listed in `REFERENCES.md` and in the presentation. Rick and Morty artwork belongs to its respective rights holders; this is an unofficial educational project with no affiliation or endorsement. Third-party artwork is not licensed by this repository.
